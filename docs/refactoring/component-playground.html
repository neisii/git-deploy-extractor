분석 단계 (스토어에서 파생)

Extract 목록 (신규 모델)

체크하면 Extract 대상 목록으로 이동, Extract 목록의 ×를 누르면 원래 목록으로 복귀합니다. 누락된 의존성은 + 파일 추가 팝업의 HEAD 트리에서 붉은 글자(+ Impl/I 배지)로 표시되며 ×로 되돌리면 그 트리로 돌아갑니다. 직접 검색으로 추가한 파일은 원래 목록이 없어 ×가 철회(삭제)입니다.

Export 시뮬레이션

추출 위치가 저장소와 겹치면(같음·저장소 안·저장소를 포함) 두 모드 모두 Export가 비활성화됩니다. 경로를 고르지 않아도 비활성화(저장소 루트 기본값 폐지). "바로 추출"은 폴더가 비어 있을 때만 허용. 폴더 생성 방식은 덮어쓰기 확인 후 진행.

팝업 (openPopup 하나만)

팝업 크기는 720×480px(기존 480×320의 1.5배)입니다. 끄면 부모 높이와 무관한 고정 480px이 되어, 아래 슬라이더로 작업 영역을 낮추면 팝업이 잘립니다. 팝업은 종류와 관계없이 동시에 하나만 열립니다(파일 추가 / 제외 패턴 / Deleted / 경고). Delete List 영역은 없어졌고, PreviewSummary의 Deleted: N을 클릭하면 삭제 파일 목록 팝업이 열립니다.
